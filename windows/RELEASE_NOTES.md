## Windows 自动任务

- 简化为每日定时执行，移除登录和锁屏触发
- 移除主界面的安装路径，安装后通过开始菜单的「小狼毫自动任务」入口再次打开
- 自动同步与自动重新部署独立开关，分别设置每日执行时间
- 保留立即执行、结果反馈、计划修改、停用和移除功能
- 每次执行读取小狼毫当前安装位置，正常原地升级无需重建计划

支持 Windows 10 22H2／Windows 11 x64，使用系统包含的 .NET Framework 4.8，无需 PowerShell。

### 更新说明

从旧预览版更新时，请关闭原窗口，打开新版程序，确认每日执行时间并点击「更新程序并保存」。保存后移除旧登录、锁屏触发，已有定时时间保留。原来没有定时的计划会预填 20:00，请确认或调整后保存。

### 使用前请注意

- 定时执行需要用户已登录，锁屏时也照常执行。睡眠、休眠和退出登录不等于锁屏，程序不主动唤醒电脑
- 同步目录仍需在 Rime 中配置，跨设备传输需要另行配置同步工具
- 原有脚本创建的计划需要先手动停用，避免重复执行
- 卸载时先移除计划，再关闭窗口，手动删除已安装程序及开始菜单快捷方式
- 本版程序尚未进行代码签名，请核对官方来源和附件 SHA-256
- 其他平台与架构暂未提供

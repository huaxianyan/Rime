## Windows 首版

- 提供独立的自动同步与自动重新部署开关
- 支持当前用户登录后、锁屏时和每日定时执行
- 提供立即执行、结果反馈、计划修改、停用和移除
- 安装到当前用户的固定目录，无需管理员权限
- 每次执行读取小狼毫当前安装位置，正常原地升级无需重建计划
- 通过同一 EXE 完成设置和计划执行，无需 PowerShell

支持 Windows 10 22H2／Windows 11 x64，使用系统包含的 .NET Framework 4.8。

### 使用前请注意

- 同步目录仍需在 Rime 中配置，跨设备传输需要另行配置同步工具
- 原有脚本创建的计划需要先手动停用，避免重复执行
- 卸载时先移除计划，再关闭窗口并手动删除已安装程序
- 本版程序尚未进行代码签名，请核对官方来源和附件 SHA-256
- 其他平台与架构暂未提供
